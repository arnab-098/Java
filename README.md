# Java Code Repository

A collection of Java programs demonstrating various concepts such as data structures, multithreading, GUI development, and custom exception handling.

## Project Overview

This repository includes Java programs that cover fundamental and advanced topics, providing practical examples and implementations.

### Key Files

* **`CustomException.java`**: Demonstrates the creation and usage of custom exceptions in Java.
* **`CustomSort.java`**: Implements a custom sorting algorithm.
* **`GUIStudent.java`**: A GUI application for managing student information.
* **`GUITest.java`**: Test class for `GUIStudent.java`.
* **`Heap.java`**: Implementation of a heap data structure.
* **`IteratorTest.java`**: Demonstrates the use of iterators in Java collections.
* **`LinkedList.java`**: Custom implementation of a singly linked list.
* **`ParseTest.java`**: Tests for parsing operations.
* **`Queue.java`**: Implementation of a queue data structure.
* **`ThreadTest.java`**: Demonstrates multithreading in Java.
* **`volatileTest.java`**: Tests for the `volatile` keyword in Java.

## Technologies Used

* **Programming Language**: Java
* **Libraries/Frameworks**: Swing (for GUI development)

## Getting Started

### Prerequisites

* Java Development Kit (JDK) installed on your system.
* A text editor or Integrated Development Environment (IDE) such as IntelliJ IDEA, Eclipse, or Visual Studio Code.

### Compilation and Execution

1. **Clone the repository**:

   ```bash
   git clone https://github.com/arnab-098/Java.git
   cd Java
   ```



2. **Compile a Java file**:

   ```bash
   javac FileName.java
   ```



3. **Run the compiled Java program**:

   ```bash
   java FileName
   ```



Replace `FileName` with the name of the Java file you wish to compile and run.
